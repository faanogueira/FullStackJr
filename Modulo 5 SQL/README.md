# ☕ Projeto SQL - Cafeteria BomGosto

Este projeto tem como objetivo controlar as vendas de café da cafeteria BomGosto utilizando comandos SQL. A estrutura contempla criação de tabelas, inserção de dados fictícios e consultas para análise de vendas e faturamento.

## ▶️ Como Executar

1. **Instale um banco de dados SQL** (MySQL, PostgreSQL ou SQLite).
2. **Crie o banco de dados**:
   ```sql
   CREATE DATABASE bomgosto;
   USE bomgosto;```
3. **Execute os scripts na ordem abaixo**:
- ```create_tables.sql```
- ```insert_data.sql```
- Qualquer uma das consultas (```consulta_*.sql```) conforme desejado.
4. **Ferramentas recomendadas**:
- MySQL Workbench
- DBeaver
- SQLiteStudio
- pgAdmin (PostgreSQL)

## 📊 Consultas SQL
Cada consulta responde a uma necessidade da cafeteria:
1. Cardápio ordenado por nome
2. Comandas com itens detalhados
3. Valor total por comanda
4. Comandas com mais de um tipo de café
5. Faturamento total por data
